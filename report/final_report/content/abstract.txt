Most document forgery detectors look for traces that editing leaves in the image: sharp edges around pasted digits, a font that does not quite match, or JPEG artefacts that differ from the rest of the page. Generative inpainting leaves very few of these traces. On receipts and forms whose numbers were repainted with commercial AI editors, published detectors score only 0.563 to 0.751 AUC. An inpainting model, however, changes one value at a time and has no idea how that value is tied to the rest of the document. A changed subject mark no longer adds up to the printed total, and a changed amount on a receipt no longer matches cash minus total.

This project builds on that observation. We describe a structured document as a set of rules between its fields and call the set of rules an edit breaks its violation signature. The signature depends only on the values, so it is the same for a crude edit and for a very realistic one. We prove that the signature can tell which kind of field was changed but, in general, not which field: fields that appear together and interchangeably in every rule cannot be separated by any rule-based method. Our system, Constraint Violation Propagation (CVP), therefore uses the broken rules to shortlist the fields that could have been edited and a visual tamper heatmap (a ResNet-18 U-Net over the image and its Error Level Analysis) to pick one of them. A shared CRNN reads the fields, and a small learned head combines the two kinds of evidence.

We built six synthetic document types with their own rules and forgers (an academic transcript, a GST tax invoice, a shop receipt, a course certificate, an ICAO-style specimen passport and a student ID card) and tested CVP on 9,000 test documents whose blended edits came from a generator that no model saw during training. CVP names the edited field for 87.6% to 92.4% of tampered documents, against 81.0% to 89.7% for the visual model alone, and it flags 97.6% to 100% of blended edits, of which the visual model alone catches only 13% to 67%. On 474 real receipt photographs from the CORD dataset that we forged with known ground truth, CVP raises detection AUC from 0.546 to 0.746 and attribution from 60.0% to 73.1% over a zero-shot visual model. On real forgeries made by people (the Find it again! dataset), forged receipts break a receipt rule almost twice as often as genuine ones (32.2% against 17.2%). The project also includes an interactive web application, 346 automated tests and scripts that rebuild every result from scratch on an 8 GB laptop.
