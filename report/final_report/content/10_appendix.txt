## APPENDIX B: HOW TO RUN THE PROJECT

The commands below are run from the project folder in a terminal. The first command needs an internet connection to install the Python packages; everything else runs offline on the laptop.

!table Table B.1: Main Commands of the Project
!widths 38,62
!opts firstbold
Command | What it does
./setup.sh | Creates the Python environment, installs the locked dependencies and runs the tests
.venv/bin/python app.py | Starts the application at http://127.0.0.1:7860 (or double-click Start CVP.command)
.venv/bin/python -m pytest | Runs all 346 automated tests
./scripts/reproduce.sh | Rebuilds every synthetic-data result from scratch (a few hours)
./scripts/reproduce.sh evaluate | Re-runs only the evaluation and figures from cached features
./scripts/reproduce_real.sh | Rebuilds every real-data result from the downloaded CORD and Find it again! data
report/build.sh | Builds the IEEE paper (PDF) and the zip for Overleaf
.venv/bin/python scripts/build_report.py | Builds this report as a Word document
!end
