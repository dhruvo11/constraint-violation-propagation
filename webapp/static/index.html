What is it?

Your file never leaves this computer. Receipts are read end to end, so unusual layouts can be misread: the page shows every reading, and you can correct one and re-check.

Is this document genuine?

Pick an example, forge a document, or upload one. CVP reads it, checks the document's own rules (sums, totals, check digits, dates) and looks at the pixels. Then it tells you whether it was edited, which field, and why.

    How CVP works

    Forgers edit pixels; documents have arithmetic. An AI image editor can repaint a number so well that no pixel looks wrong, but it does not know that the number must still add up with the rest of the page. CVP uses both kinds of evidence:

    1. Read every field with OCR.
    2. Check the rules of the document type: sums, totals, tax, change, check digits, dates.
    3. Shortlist the fields the broken rules fit. Often that's one field. When several fields fit equally, no rule can separate them (Proposition 1 in our paper).
    4. Look at the pixels: a neural network paints a heatmap of edit traces.
    5. Decide: the heatmap picks among the shortlisted fields, even when it's too weak to judge the whole page.

    What we measured

    All numbers come from the project's saved results (the paper and the final report). AUC: how well a method separates edited from genuine documents (0.5 = guessing, 1 = perfect). Attribution: how often it names the edited field.
